PageLive for ChatGPT

Keyboard-first workflows and accessibility-friendly announcements to make ChatGPT navigation faster, clearer, and more predictable.

ChatGPT Default Features

For ChatGPT's default shortcuts can be viewed by pressing Ctrl+/

For Power Users

Focus Chat Input

Press Shift + Esc to jump directly to the chat input and continue typing without breaking flow.

Start New Chat

Press Ctrl + Alt + O to open a fresh chat immediately.

Page Info Dialog

Press Alt + / to open Page Info for active chat metadata and quick navigation context.

For Screen Reader Users

Page Info Dialog

Press Alt + / to open Page Info Dialog and press Escape to close. Quick info about the page, like the chat title and the number of responses, are located at the top of the dialog. The info is meant to give snapshot information to users saving users from the hassle to navigate through the page.

Read Last Response

Press Ctrl + Shift + Enter to hear the most recent ChatGPT response on demand.

New Response Announcement

PageLive announces when a new assistant response is available, so you know when new content is ready to read.

Sidebar Toggle Announcement

ChatGPT's native feature allows users to toggle sidebar by pressing Ctrl + Shift+ S. However the absence of announcement will leave screen reader users clueless about the sidebar's state. To overcome the issue PageLive announces the state of the sidebar everytime sidebar collapsed of expanded.

Shortcut Dialog Close Announcement

When ChatGPT shortcut dialog opens, screen reader announces it. However when you close the dialog, either by pressing Escape or pressing the close button, the dialog is closed without an announcement, which can be confusing. PageLive announces when the shortcut dialog is closed, so you have clear feedback.

Fix Unreadable Keyboard Shortcuts

ChatGPT's keyboard shortcuts in the dialog can not be read by screen reader. To solve the issue, PageLive will append each keyboard shortcut to its corresponding label so they can be read by screen reader. PageLive also translate some keyboard symbols to be readable, for example Enter key symbol and Escape key symbol.

Prompting and New Response

PageLive provide features below to improve your experience in submitting prompts and receiving new responses.

  • In the time gap between prompt and receivng new response, PageLive provides audio cues like "loading.." as indication that the user interface still waiting for the new response.
  • PageLive will automatically read the new response once completely received.

Global Search Dialog

ChatGPT provides Global Search Dialog, keyboard shortcut Ctrl + K, allowing users to search and quickly navigate between chats and start new ones. Below are PageLive's improvements related to the Global Search dialog

  • When the Global Search dialog opens or when the chat list below search box is updated, PageLive announces the total number of chats in the list, so you have a clear overview of what is going on on the dialog.
  • While the focus is still in the search box, ChatGPT provides a feature allowing user to move highlighted chat title by pressing up/down keys. Pressing Enter will load the respective chat. This is a great feature, however the highlighted chat title is not announced by screen reader, which can be confusing. PageLive announces the highlighted chat title as you move up/down, so you know which chat is currently highlighted. You either can press Enter to open the announced chat or continue typing to filter the chat list with the search box, without needing to switch focus to the search box first.
  • PageLive announces when the Global Search dialog is closed.
